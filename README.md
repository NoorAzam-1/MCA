## Resource Types

- **Notes** — Compiled study notes for full syllabus coverage
- **PPT** — Class/contact programme presentation slides
- **PYQ** — Previous year term-end exam question papers
- **Solutions** — Step-by-step answers to previous year papers
- **Guess Paper** — Important/expected questions for exam prep

## How to Use

1. Open the folder for your subject (search by course code).
2. Start with Notes/PPTs for concept building.
3. Solve PYQs, then verify from the solutions PDF.
4. Revise using guess papers before exams.

> All materials are for personal academic use. Official books and papers are available on [eGyanKosh](https://egyankosh.ac.in/) and the [IGNOU website](https://www.ignou.ac.in/).
